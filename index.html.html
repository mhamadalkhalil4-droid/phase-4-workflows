Actors: System · Payer · Bank  ·  Screens: SCR-PAY-004 Standard and Extended
⚙️ Threshold is 2 total retrials on the mandate regardless of rejection reason.

8Signature Issues — Full Trial Flow (RR01, RR02)
Actors: System · Bank · Payer (contacted only after all silent attempts fail)  ·  Screen: SCR-PAY-002
⚙️ Important: The payer is NOT contacted at the start. The system silently tries all stored signatures with the bank first.
Only after all attempts in a trial fail does the system send a correction link to the payer to draw new signatures.
Each trial = up to 5 signature submissions + 1 EID signature (Trial 1 only) = max 6 submissions per trial.
Dashboard Retrials column format: 1 (3) / 3 — number in brackets = bank submissions attempted in current trial.
